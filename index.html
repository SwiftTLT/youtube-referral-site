YT-Referral

A personal, single-user tool for summarizing referred YouTube videos.

YT-Referral lets its one operator save a video to a small set of YouTube playlists (using YouTube's own "Save to playlist" button) to request a written summary of it. A background process reads those playlists, fetches each video's public metadata and captions, writes a summary note into the operator's private notes, and removes the video from the playlist.

A second part of the tool checks a short, operator-chosen list of YouTube channels once a day and adds new uploads to a holding playlist, so the operator can choose which ones to summarize. Nothing is summarized automatically.

This application has exactly one user — its operator — and is not distributed, sold, or offered to anyone else. It is not a public service and does not accept sign-ups.
